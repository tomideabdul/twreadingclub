# The Wildkhard Reading Club

Website of The Wildkhard Reading Club: the club story, every book read since February 2022, events, Twitter Spaces and reviews, and The Khard and Kulture Podcast.

A single static page (`index.html`) with no build step.

## Live site
Published with GitHub Pages: https://tomideabdul.github.io/twreadingclub/

To turn it on: Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.

## Editing
Book data, links, Spaces, events and bio sit in the script block of `index.html` (search for `CONFIG`, `B=[` and `EV=[`).
