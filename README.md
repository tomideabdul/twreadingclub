# TWRC

Website of The Wildkhard Reading Club: the club story, every book read since February 2022, events, Twitter Spaces and reviews, and The Khard and Kulture Podcast.

It is a single static page (`index.html`) with no build step.

## Publish with GitHub Pages
1. Create a new repository named `TWRC` and upload these files to the root.
2. Go to Settings > Pages, choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
3. The site will be live at `https://<your-username>.github.io/TWRC/`.

## Editing
Book data, links, Spaces, events and bio sit in the script block of `index.html` (look for `CONFIG`, `B=[` and `EV=[`).
